# 🧠 SOBRE O PROJETO

O HENRIQ-JS TERMINAL nasceu da ideia de transformar o Termux Android em um verdadeiro sistema hacker futurista inspirado em:

- Kali Linux
- BlackArch
- Matrix
- Mr Robot
- Cyberpunk 2077
- Linux terminals reais

A maioria dos “terminais hackers” existentes são apenas interfaces falsas ou apenas efeitos visuais.

Então eu quis criar algo:
- bonito
- útil
- funcional
- profissional
- cyberpunk
- focado em programadores

Tudo funcionando diretamente no:
- Android
- Termux
- NodeJS
- Android TV
- TV Box

Usando apenas:
- JavaScript
- NodeJS
- ANSI Escape Codes
- Linux Shell
- Um único arquivo `.js`


```text

CTRL + X
```

# ▶ EXECUTAR O TERMINAL

```bash

```

━━━━━━━━━━━━━━━━━━━━━━━━━━

# ⚡ EXECUTAR MAIS RÁPIDO

```bash
echo "alias henriq='node ~/henriq-js.js'" >> ~/.bashrc
```

```bash
source ~/.bashrc
```

Agora basta usar:

```bash
henriq
```
