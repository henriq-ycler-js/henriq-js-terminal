O **HENRIQ-JS TERMINAL** foi criado para transformar o Termux Android em uma experiência cyberpunk real para programadores.

Inspirado em:
- Kali Linux
- BlackArch
- Matrix
- Mr Robot
- Cyberpunk 2077
- Linux terminals reais

O projeto combina:
- NodeJS
- Linux Shell
- Ferramentas DEV
- Interface ANSI Cyberpunk
- Android Integration
- TV Box Support

Tudo funcionando dentro de um único arquivo JavaScript.

# 📥 INSTALAÇÃO

## Atualizar Termux

```bash
pkg update -y && pkg upgrade -y
```

---

## Instalar dependências

```bash
pkg install git nodejs nano curl wget python vim zip unzip -y
```

---

## Clonar repositório

```bash
git clone https://github.com/henriq-ycler-js/henriq-js-terminal
```

---

## Entrar na pasta

```bash
cd henriq-js-terminal
```

---

## Criar package.json

```bash
npm init -y
```

---

## Criar arquivo principal

```bash
nano henriq-js.js
```

Cole o código do terminal.

---

## Salvar arquivo

```text
CTRL + O
ENTER
CTRL + X
```

---

## Executar terminal

```bash
node henriq-js.js
```

---

# ⚡ EXECUÇÃO RÁPIDA

```bash
echo "alias henriq='node ~/henriq-js-terminal/henriq-js.js'" >> ~/.bashrc
```

```bash
source ~/.bashrc
```

Agora basta usar:

```bash
henriq
```
